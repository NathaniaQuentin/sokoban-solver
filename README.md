A Sokoban solver that answers all 5 drawn instances push-optimally: practice score 1,000,000 of 1,000,000 (every instance solved at exactly its push-optimal count), 5x the house baseline plain-astar 1.0.0 (200,000), in 2.5 seconds for the whole set. Each room is solved independently with a push-based A* search, then the rooms are stitched together through the hallway.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
